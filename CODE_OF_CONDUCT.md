# Code of conduct

## The short version

Be decent to each other. This is a free plugin maintained in people's spare time, and nobody is owed anything by anybody.

## What that means

**Assume good faith.** A confusing bug report is usually somebody struggling to explain a real problem, not somebody wasting your time.

**Critique code, not people.** "This query runs on every request" is useful. "This is amateur work" is not.

**Remember the range of people here.** Contributors and users have wildly different levels of experience, different first languages, and different amounts of time. Somebody's first pull request should not be their last.

**Maintainers can say no.** A feature that does not fit the plugin can be declined without it being a judgement on the person who proposed it. "Not for this project" is a complete answer.

## Not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption, or publishing somebody's private information. None of this is welcome in issues, pull requests, commit messages or anywhere else the project happens.

## If something goes wrong

Email **mymail.anupam@gmail.com**. Reports are handled privately. Consequences range from a request to change behaviour up to a permanent ban, depending on severity.

Maintainers are held to this standard too — more strictly, not less.
